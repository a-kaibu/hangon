# 反魂麻雀 (hangon)

ブラウザだけで遊べる 4 人打ちリーチ麻雀です。CPU 3 人と対戦します。ゲーム本体は素の JavaScript で、3D 表示のみ [Three.js](https://threejs.org/) をビルド時に同梱しています (実行時に外部から読み込むものはありません)。開発ツールは [Vite+](https://viteplus.dev/) (`vp`) で、`main` への push で GitHub Actions がビルドして GitHub Pages にデプロイします。

## 遊び方

- GitHub Pages: `https://a-kaibu.github.io/hangon/`
- ローカル: `vp install` → `vp dev`

マウスはクリックで打牌、スマホは 1 回タップで選択 (情報表示)、もう 1 回で打牌です。

## 機能

- ルール: 赤ドラ 3 枚・喰いタン・後付けあり、25000 点持ち 30000 点返し、トビあり、東風戦/半荘戦
- 役: 1 翻〜役満まで一通り (天和・地和・九蓮・国士十三面など含む)、符計算、満貫以上の切り上げ、本場・供託
- 進行: チー / ポン / 明槓 / 暗槓 / 加槓 (槍槓)、喰い替え禁止、リーチ (一発・ダブルリーチ・リーチ後の暗槓制限)、フリテン (捨て牌・同巡・リーチ後見逃し)、海底/河底/嶺上、九種九牌・四風連打・四家立直、流局時のテンパイ料、連荘
- CPU の強さ: やさしい / ふつう / つよい
- アシスト (設定で個別にオンオフ)
  - シャンテン数・待ち・フリテン表示
  - おすすめ打牌のハイライト
  - リーチや仕掛けに対する手牌ごとの危険度 (現物・筋・壁・字牌の見え枚数) と理由
- 「遊び方」: ルールの基本 (ゴール→牌の種類→面子→1巡の流れ→聴牌と和了→役→鳴き→フリテン→点数→守り方) を順に読める初心者ガイド
- 役一覧 (検索・牌姿の例・鳴いた時の翻数)、危険牌の見方の解説
- 対局の途中経過を自動保存し、リロードしても続きから再開 (設定の「新しい対局を始める」でリセット)
- WebGL (Three.js) による 3D の卓: 角丸と厚みのある牌、照明と影、打牌のアニメーション (設定でオフ可、WebGL が使えない環境では平面表示)、誤打防止の 2 回タップ打牌

## アルゴリズム

- **シャンテン数**: 色ごとに (面子数, 塔子数, 雀頭) のパレート最適な組をメモ化 DFS で列挙して合成する一般形の計算 + 七対子 + 国士無双。
- **牌効率**: 打牌候補ごとに「シャンテン数 → 有効牌の残り枚数 (自分から見えている牌を除く)」で評価。「つよい」は一向聴のとき、各有効牌を引いた後の最良聴牌の待ち枚数まで読む 2 手先評価を加える。
- **守備 (押し引き)**: 相手ごとの聴牌気配 (リーチ = 1、副露数と巡目から推定) と、牌ごとの放銃率の目安 (現物 0%、筋・壁・ワンチャンス・字牌の見え枚数・ドラ補正) を掛け合わせ、自分の手の打点見込みとシャンテン数で決まる重みで減点する。放銃率の数値は、公開されている対リーチ牌種別放銃率の統計の傾向にもとづく概算。
- **鳴き**: 鳴いた後に役 (役牌・断幺九・染め手・対々和) の見込みがあり、シャンテン数が進むときだけ鳴く。

CPU 同士の対戦シミュレーション (`npm run sim`) で、点数の合計が常に 100000 点になることと強さの序列を確認しています。

## 開発

```
vp install    # 依存のインストール
vp dev        # 開発サーバー
vp check      # フォーマット + lint
vp test       # 役・符・点数・シャンテンの単体テスト + CPU 対戦
vp build      # dist/ に本番ビルド
vp run sim    # CPU 対戦 200 半荘の成績
```

デプロイは `.github/workflows/deploy.yml` (setup-vp → check → test → build → deploy-pages)。リポジトリの Settings → Pages の Source は「GitHub Actions」にしてください。

URL に `?open` を付けると CPU の手牌が見えるデバッグ表示になります。
